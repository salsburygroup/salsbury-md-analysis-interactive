# Interactive tutorials and how-to guides

Run the core analysis before using these pages. The interactive command reads a
completed analysis directory and writes an offline browser. It does not read
raw trajectories or submit analysis jobs.

The three NEMO tutorials continue the matching example in the core repository:

- [NEMO on a workstation](nemo_zinc_finger_workstation/README.md)
- [NEMO on a Slurm cluster](nemo_zinc_finger_cluster/README.md)
- [NEMO on WFU DEAC](nemo_zinc_finger_deac/README.md)

Use the task-focused how-to guides for a campaign built from your own files:

- [Build and review a report on a workstation](workstation/README.md)
- [Build and transfer a report from a Slurm cluster](cluster/README.md)

Each page links back to the core instructions that create its analysis
directory. Keep the complete `interactive-report/` folder when moving or
sharing a report because its evidence links are relative.
